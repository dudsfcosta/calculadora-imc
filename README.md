# 🧮 Calculadora de IMC

Uma aplicação web simples e interativa, desenvolvida para calcular o Índice de Massa Corporal (IMC) a partir do peso e da altura informados pelo usuário. O projeto tem o objetivo de ser uma ferramenta acessível para ajudar na busca por um padrão de vida saudável.

## 🚀 Funcionalidades

- Interface amigável para inserção de **Peso (Kg)** e **Altura (m)**.
- Cálculo automático do IMC ao clicar no botão "Calcular IMC".
- Classificação do resultado baseada no valor numérico do IMC, indicando se o usuário está:
  - Abaixo do peso
  - No peso normal
  - Com sobrepeso
  - Com obesidade grau I
  - Com obesidade grau II
  - Com obesidade mórbida

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as três linguagens fundamentais da web:

- **HTML5:** Para a estruturação semântica do conteúdo, incluindo formulários e seções.
- **CSS3:** Para o estilo visual, utilizando fontes customizadas (*Roboto*), reset de margens, layout com CSS Grid e design com sombras e gradientes no cabeçalho.
- **JavaScript:** Para implementar a lógica do cálculo matemático e as estruturas condicionais (if/else) que atualizam os resultados na tela (DOM) de forma dinâmica.

## ⚙️ Como executar o projeto localmente

Não é necessária a instalação de nenhuma dependência ou servidor para rodar este projeto.

1. Faça o download de todos os arquivos (`index.html`, `style.css`, `script.js`).
2. Mantenha os três arquivos na mesma pasta.
3. Dê um duplo clique no arquivo `index.html` para abri-lo diretamente no seu navegador padrão (Google Chrome, Firefox, Edge, Safari, etc.).
